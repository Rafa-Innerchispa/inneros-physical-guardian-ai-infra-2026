Independent stdlib-based Python/SQLite application, Meta Model API Responses integration slot, local Ollama slot, updated dashboard, distinct test suite, demo scenarios, Docker/CI and submission evidence package. We will check the official event rules before final submission, including any requirements for original code or the use of earlier work.
