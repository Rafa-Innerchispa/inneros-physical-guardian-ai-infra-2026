# Team Recruiting Brief

## Team status

Team: **InnerOS Physical Guardian**

Join requests: **open**

Preferred team size: **3 people**, maximum **4** unless an additional member brings a clearly distinct capability.

## What already exists

The team does not need generic software help. The permanent product already has real camera ingestion, edge architecture, anomaly logic, evidence concepts and local infrastructure.

Recruit for missing leverage, not duplicate capacity.

## Highest-priority teammate

### English technical presenter / pitch lead

Desired profile:
- fluent, confident spoken English;
- can understand the product architecture rather than only read a prepared script;
- comfortable presenting to technical judges and sponsor engineers;
- able to explain a demo crisply under time pressure;
- willing to rehearse jointly so technical statements remain accurate.

This role is especially valuable because the project lead can handle the product and technical depth but wants stronger spoken-English delivery for on-site judging/networking.

## Second priority

### Edge AI / embedded optimization engineer

Desired profile:
- inference deployment on constrained devices;
- ONNX / quantization / model optimization / hardware accelerators;
- computer vision pipelines;
- profiling latency, memory and throughput;
- ideally direct experience with SiMa.ai, Qualcomm, Intel/OpenVINO or similar edge runtimes.

## Optional fourth role

### Demo UX / technical storytelling

Desired profile:
- can build a clear judge-facing demo surface;
- understands event timelines, evidence and operator workflows;
- avoids decorative dashboards that obscure the engineering story.

## Public recruiting text

> Building a real-world Physical AI security platform from Ecuador using existing cameras, DVR/NVR infrastructure and local AI. We already have working Dahua ingestion, edge gateways, anomaly detection and forensic evidence architecture. Looking for an English-speaking technical presenter and an Edge AI/on-device engineer for the Santa Clara on-site hackathon. SiMa.ai is our preferred track.

## Interview / join-request screen

Ask five questions:

1. Are you planning to attend on-site in Santa Clara?
2. Which part would you personally own during the hackathon?
3. Can you explain a technical project live in English without reading a script?
4. What edge/on-device inference stack have you actually deployed?
5. Are you comfortable working on top of an existing product rather than rewriting the architecture during the event?

## Team culture

- Small team, fast decisions.
- Evidence over claims.
- Real hardware over synthetic theater when feasible.
- Existing product boundaries are respected.
- Everyone should be able to explain the core project story.
