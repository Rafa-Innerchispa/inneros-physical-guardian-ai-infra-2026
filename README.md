## Current concept
A local-first Physical AI security system that can ingest existing DVR/NVR/IP camera infrastructure, detect anomalous behavior, reason over multi-camera context, trigger governed actions, and preserve forensic evidence of what the agent saw and did.

Validation environments:
- Home lab: Dahua analog DVR + IP cameras + InnerOS local compute + Cozmo physical action path.
- Bellini pilot: Windows edge agent over existing camera estate, no mandatory new hardware in phase 1.
